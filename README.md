# Mars

**Mars** — приложение на C# Windows Forms, реализующее простую нейронную сеть для распознавания рукописных цифр от 0 до 9.

## Возможности

- Обучение нейронной сети на наборе данных.
- Распознавание рукописных цифр.
- Прямое распространение сигнала (Forward Pass).
- Обратное распространение ошибки (Backpropagation).
- Сохранение и загрузка весов нейронной сети.
- Вычисление вероятностей принадлежности изображения к каждому классу цифр.

## Архитектура нейронной сети

Нейронная сеть состоит из трех слоев:

| Слой | Количество нейронов |
|---|---:|
| Первый скрытый слой | 70 |
| Второй скрытый слой | 38 |
| Выходной слой | 10 |

На вход сети подается изображение цифры, представленное в виде массива из 15 пикселей.

Каждый пиксель кодируется одним числом:
- `0` — пиксель не закрашен;
- `1` — пиксель закрашен.

Выходной слой содержит 10 нейронов — по одному для каждой цифры от 0 до 9.

## Формат данных

Обучающие и тестовые данные хранятся в текстовых файлах:

- `train.txt` — обучающая выборка.
- `test.txt` — тестовая выборка.

Каждая строка содержит 16 чисел, разделенных пробелами:

- Первое число — правильная цифра, от 0 до 9.
- Следующие 15 чисел — значения пикселей изображения.

Каждый пиксель имеет значение `0` или `1`:
- `0` — незакрашенный пиксель;
- `1` — закрашенный пиксель.

Пример строки:

```text
5 1 1 1 1 0 0 1 1 1 0 0 1 1 1 1
```
## Функции активации

Для скрытых слоев используется сигмоидальная функция:

```text
sigmoid(x) = 1 / (1 + exp(-x))
```

Ее производная:

```text
sigmoid'(x) = sigmoid(x) * (1 - sigmoid(x))
```

Для выходного слоя используется Softmax. Она преобразует выходные значения нейронов в вероятности, сумма которых равна 1.

## Обучение

Обучение выполняется методом обратного распространения ошибки.

Основные этапы:

1. Загрузка обучающих данных.
2. Перемешивание обучающих примеров.
3. Прямое распространение входных данных через сеть.
4. Вычисление ошибки на выходном слое.
5. Обратное распространение ошибки по слоям.
6. Обновление весов нейронов.
7. Повторение процесса для заданного количества эпох.

Для выходного слоя используется градиент ошибки Softmax совместно с категориальной кросс-энтропией.

## Запуск проекта

1. Склонируйте репозиторий.
2. Откройте файл `Mars.sln` в Visual Studio.
3. Убедитесь, что файлы `train.txt` и `test.txt` находятся в каталоге, из которого приложение ожидает их загрузку.
4. Соберите и запустите проект.
